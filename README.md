# Little Lab: The Curious Coast — Version 4

An original cozy illustrated scientific research browser game. No dependencies, accounts, external art, emoji, or build tools.

## Play
Open `index.html` in a browser, or deploy it using GitHub Pages.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` to the repository root (not inside the ZIP folder).
3. In Settings → Pages, select Deploy from a branch → main → /(root).
4. Open the Pages URL once the site is published.

## Gameplay
- Explore the forest, pond and orchard to collect specimens.
- Enter the research cottage or select Research desk to conduct investigations.
- Design studies with two independent variables, record multiple trials, view data and submit an evidence-based conclusion.
- Earn grants, decorate the laboratory, keep a journal and progress through four studies.
- Autosave uses browser localStorage. Data is stored only on that device/browser.

## Notes
The experimental datasets are simplified educational simulations. They are not real experimental evidence. The game is a self-contained browser prototype with original Canvas illustrations, not an asset-rich commercial game engine.
